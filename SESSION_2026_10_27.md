### 3. CHATBOT WIDGET OPTIMIZATION

#### Before Mobile Fix
- Button: 64px × 64px (w-16 h-16)
- Window: 384px × 384px (w-96 h-96) — **covered 85% of mobile viewport**
- Position: bottom-8 right-8
- Result: **Unusable on mobile; blocks all content**

#### After Mobile Fix
**Button:**
- Mobile: 56px × 56px (w-14 h-14)
- Desktop: 64px × 64px (w-16 h-16)
- Position: bottom-4 md:bottom-8, right-4 md:right-8

**Window:**
- Mobile: `w-[calc(100vw-2rem)]` (full width with 1rem padding each side)
- Desktop: `w-96` (384px fixed)
- Mobile: `h-[60vh]` (60% of viewport height)
- Desktop: `h-96` (384px fixed)
- Max width: `max-w-sm` (prevents overflow on wide phones)
- Position: bottom-20 md:bottom-28

#### Result
- Mobile viewport now shows 25-30% chatbot, 70-75% page content
- Fully responsive without covering hero section
- Button positioning matches mobile-safe zone (not obscured by iOS notch/safe area)

## TECHNICAL NOTES

### Responsive Classes Used
```css
/* Logo sizing */
h-[4rem] md:h-[10.75rem]      /* Mobile to desktop */

/* Spacing */
px-3 md:px-6                   /* Horizontal padding */
py-2 md:py-4                   /* Vertical padding */
gap-2 md:gap-3                 /* Gap between elements */

/* Visibility */
hidden md:block                /* Hide on mobile, show on desktop */
hidden md:flex                 /* Navigation & buttons */

/* Chatbot */
w-[calc(100vw-2rem)]          /* Full width minus padding */
h-[60vh] md:h-96              /* 60% viewport mobile, fixed desktop */
bottom-4 md:bottom-8           /* Distance from bottom */
right-4 md:right-8             /* Distance from right */
```

- **sm:** 640px (not explicitly used)

- **lg:** 1024px (not needed for this iteration)
